# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability in otoxan, please report it privately.

**Do not open a public issue.**

### How to report

1. Open a [private security advisory](https://github.com/silas/otoxan/security/advisories/new) on GitHub.
2. Or email the maintainer directly (see contact below).

Please include:

- A description of the vulnerability
- Steps to reproduce (if applicable)
- The version(s) affected
- Any suggested mitigation

We aim to respond within 48 hours and will keep you informed throughout the disclosure process.

## Disclosure Policy

- Reports are acknowledged within 48 hours.
- A fix is targeted within 14 days for critical vulnerabilities, 30 days for moderate.
- Coordinated disclosure with the reporter before public announcement.
- Credit given to the reporter unless anonymity is requested.
